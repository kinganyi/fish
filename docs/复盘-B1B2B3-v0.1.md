## 2. 做对了什么（可复用，5 条）

1. **物理隔离 + 对照组**：副本是"独立目录 + 独立 git 仓 + `sqlite3 backup` 一致快照"（`开发基线-20261026.md` §2），主树零触碰**成立**；变异必带对照组（8 模块不变异必须全绿才信"红"）。→ 可复用：任何会改共享状态的交付，**先造隔离副本，再带一组"不隔离就会坏"的对照**。
2. **三视角独立审计、互不采信**：评审「不依赖实现者摘要」、QA「不采信工程师自报」、安全「逐行读 + 自建探针 + 独立挑战」。三者**各自抓到了别人没抓到的类**（逐条核过，不是客气话）：
   - **QA 独有 4 条**：junction 遍历越界（F-QA-2，唯一由 QA 独立发现的阻断项）、`search` 只给相对路径、`tree` 列附件名、变异脚本在 cp936 下不可复跑；
   - **评审独有 2 条**（都在第二轮）：交付门禁红灯而文档说 17/17（🟠-N2）、P0 判据 KB-2 缺"每目录最近修改"（🟠-N3）；另外"非 UTF-8 写"与"回滚凭据"是评审先定级为 🟠，安全从"异常逃逸/假保证"另立条目；
   - **安全独有 5 条**：忽略规则大小写/尾随空格绕过、8.3 短名绕过、MCP 写面无身份门槛、凭证文档可读、`bool("false")` fail-open——**全部是"对抗形态"，功能测试与常规评审都不会自然想到**。

   **这是本批最值钱的结构**：三棒的**漏项不重叠**。
3. **每条修复配判据 + 变异；改判据必须证明"判别力没降"**：31 条定点修复逐条给出「判据位置 + 变异 id」；评审专门有 C 节判定"测试改动合法且提高判别力，无旧判据被削弱"。
4. **偏离记录 = 行为变更登记**：每处与设计/PRD 不一致都写「设计说 / 实际 / 为什么」，第二轮起还登记"人能看出差别"的行为变更。合并手册、帮助文档、下一批估算全从这里取料——**交接成本主要由它压缩**。
5. **边界诚实声明**：`≈85%/87%` 覆盖率是**估算不是实测**；"零写入"的证据是 **mtime 快照 diff 不是审计级**；"判不到 = 不计 PASS"；"`allow_sensitive` 是模型可自授的开关，不是人机二次确认"写进报告而不是藏起来。→ 下游因此知道**哪条结论能依赖、哪条只能参考**。
