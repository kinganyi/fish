# 04 · 主动服务（hooks）

> 一句话：**MCP 是手（不伸就没有），hook 是神经反射（该响就响）。fish 两条都长。**

## 1. 能力面：为什么只有 hook 能"强制"

| 通道 | 能不能强制 | 依据 |
|---|---|---|
| MCP tools | ❌ | 由模型决定调用；不调就没有 |
| MCP resources | ⚠️ 半强制 | 宿主可以预加载，但由宿主决定 |
| **宿主 hooks** | ✅ | 事件驱动，宿主保证执行 |

这就是 fish 把"主动服务"全部押在 hook 上的原因：**注入、采集、拦截，都必须不依赖模型想起来。**

## 2. 支持的事件与 fish 的用法

| 事件 | fish 用它做什么 |
|---|---|
| `SessionStart` | 签发 token + 注入包（身份/坐标/规矩/注意/索引 + as-of）+ 自动签到 |
| `UserPromptSubmit` | 按提示词递记忆（命中 1–3 条）；「继续」→ 断点 |
| `PreToolUse` | 撞车判定（`ask`/`warn`）；不阻塞时零输出 |
| `PostToolUse` | 动作采集（只路径/摘要）+ 每 N 次推 1 条候选 |
| `Stop` | 沉淀提醒（可选） |
| `SubagentStart/Stop` | 子代理身份继承/产出回收（可选） |

## 3. 动作采集：只记路径，不记内容

```sql
tool_activity(session_key, citizen_id, tool_name, action,
              path_dir, path_abs, args_digest, ok, seen_at)
```

- 只收集**写类工具**的路径与 16 位参数摘要；**文件内容/命令原文/prompt 一律不落盘**。
- 隐私工程细节：**匹配字段与落盘字段分离**——命令只参与"是不是在写 fish"的匹配，
  落盘时折成 `bash:<命令名|len>#sha8`；心跳里的 session 是 8 位哈希。
- **为什么**：这是"观测"而不是"监控"；采集到的只是"谁在哪块动了"，不是"改了什么"。

## 4. 提示词递记忆

- 输入：`prompt` 文本 → 关键词/编码/项目名 → 检索 → **相关性 × 陈旧性**门槛 → 命中才附。
- **陈旧性用内容年龄**（`occurred_at` / `recorded_at`），不用 `last_accessed_at`——后者会被"展示"刷新，把老事实当新鲜。
- 频率闸 + 去重（同一 prompt 不重复递）；无身份时按"匿名"处理（不因身份失败整体失效）。
- 输出是 `additionalContext`（不阻塞）。

## 5. 撞车 ask（保守拦截）

- 只在**真实重叠 + 对方活跃**时触发；`warn` 默认不阻塞，靠「下一次 PostToolUse 递一句」到模型眼前。
- `ask` 依赖宿主"允许需要批准的动作"——**宿主关闭批准时，`ask` 等于拒写**（所以默认 `warn`）。

## 6. 注入包（SessionStart 的主角）

五段，按预算装配与裁剪：

| 段 | 内容 | 来源 |
|---|---|---|
| ① 身份 | 登记身份/主人/三条铁律 | token → citizens |
| ② 坐标 | 在哪个项目/档期/工作区 | project_stints + workspace_map |
| ③ 规矩 | 本项目硬规则 + 全局规范 | `mem_type='rule'` |
| ④ 该注意什么 | 未闭合 / 最近的坑 / 高价值未读 | 标题关键词 + lesson + knowledge_gaps |
| ⑤ 索引 | 可查项目/衰减参数/操作指引 | code_registry |

纪律：预算硬上限、**裁剪顺序固定**（索引先裁、身份永不删）、**显式 as-of**、空段不出噪音。

## 7. 方言与性能（真实踩坑）

- **matcher 语义因宿主而异**：有的按字面、有的按正则。非法 matcher 会让**整份配置被拒**（一个事件都不注册）——所以安装器做"只认纯字面备选"的方言契约校验，并用宿主出厂 parser 复核。
- **hook 是进程外串行命令**：PreToolUse 走不 import 主程序的快路径（只读快照），目标 <50ms；失败一律静默（不能拖垮工具调用）。
- 装配是**启动读一次**：改 hooks 配置需要重启；脚本改动不需要。

## 8. 边界

- 观不到"模型思考"，只观得到工具与提示词。
- 观不到"工具失败"（无 failure 事件时用 `tool_response` 文本启发式，标未知）。
- 非工具改文件（别的进程/手工）不可见——所以看板永远有"推断"字样。
