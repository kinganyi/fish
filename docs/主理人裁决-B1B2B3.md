## 四、附加技术裁决（PRD 未列，但实现必须定）

1. **看板旧渲染文件的处置**：`p0/data/projects/<项目>/看板-*.md` 是投影，迁移后**重新渲染到 `fish-home` 并删除旧文件**（删除前逐条记录路径与 sha256 到交付报告）；`.gitignore` 增加 `p0/data/projects/**/看板-*.md`，并把已误提交的 4 个看板文件 `git rm --cached`（保留磁盘）。
2. **迁移幂等**：`boards.path` 迁移写成 `migrate()` 链尾的幂等步骤（只改以 `projects/` 开头或根板旧形态的行），重复执行不重复改写。
3. **`fish-home` 生成物**：整个目录 gitignore；任何渲染不得写 `p0/data`（HOME-6 判据）。
4. **知识库写路径**：只写 `mode=rw` 的 vault；写前备份到 `p0/data/_backups/kb/<vault_id>/<ts>-<slug>/`；原子写（临时文件 + `os.replace`）；写后重读校验 sha256。
5. **知识库读路径**：文件系统为底座，Obsidian CLI 仅作 `kb doctor` 探测增强（app 未运行 → `available=false`，不影响任何读写）。
6. **隐私**：`kb_access.meta` 只存 `query_hash`（sha256 前 12）、长度、耗时；不存 query 原文、不存正文。
7. **不新增第三方依赖**（Python 3.11 标准库）；Windows 路径必须用 `commonpath` 判越界，禁止 `startswith`。
