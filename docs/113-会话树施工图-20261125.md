### 5.5 递归吊销 SQL（与四个坑）

```python

  SELECT token_hash FROM session_tokens WHERE parent_token = ?
  UNION
  SELECT s.token_hash FROM session_tokens s JOIN t ON s.parent_token = t.hash
```

改法（只换 `parent_token` 那一支，另三口径 `:3608-3612` 一个字节不动）：
