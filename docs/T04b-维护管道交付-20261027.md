### 2.2 `run_maintenance(conn, root, *, only=None, now=None, deps=None, force=False)`
- 判定顺序：`enabled=0` → skipped(disabled)（`force` 也不越过）→ 间隔内 → skipped(interval) → 执行；
- 单任务异常记 `error` 并**继续后续**；只有 `ok/error` 更新 `last_run_at`（skipped 不推进时钟）；
- 依赖注入（模块**不 import fish**）：`archive_citizens` / `reindex_fts` / `build_links_on_write` / `get_config` / `corpus_ingest` / `corpus_retag`；缺依赖 → skipped(`dep_missing:…`)。

### 2.3 七任务
| 任务 | 行为 | 关键点 |
|---|---|---|
| `kb_reindex` | `fish_kb_index.rebuild_kb_index(mode='incremental')` | affected=`added+updated+deleted`；detail 带 errors |
| `links_rebuild` | 悬空边 `suppressed=1`；两端 active 恢复 `0`；可选对近 7 天 code 补建 | **不物理删边**；补建依赖 `build_links_on_write`，缺则 `skipped_dep` |
| `push_log_prune` | ①已判定且 >90 天且非 `kb:%` ②`activity:*` 超保留期 | 两段独立计数；`activity.retention_days<1` 跳过该段 |
| `citizens_archive` | `session.archive_after_days`（0=关） | 0 → skipped(`disabled_by_config`)；调用 `fish.archive_citizens` |
| `fts_verify` | `memory_fts` 行数 vs `code_index` | 不等 → `fish.reindex_fts`；相等 affected=0 |
| `corpus_ingest` | `corpus.daily_enabled`（默认关） | 显式 `days=DEFAULT_WINDOW_DAYS`（=3，6d7f2ac 口径） |
| `corpus_retag` | `corpus.daily_retag`（默认关） | 显式传解析器，未知项如实 unmapped |
