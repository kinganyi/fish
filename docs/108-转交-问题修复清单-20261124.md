**现象**

- `schtasks /query /tn "\fish_daily_report" /v /fo LIST`：`Last Run Time 2026-11-23 23:00:01`、`Last Result 267014`、`Next Run 2026-11-24 23:00:00`。

**根因（可证伪）**

**影响**

**验收**
