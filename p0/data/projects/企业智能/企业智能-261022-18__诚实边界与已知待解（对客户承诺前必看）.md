# 诚实边界与已知待解（对客户承诺前必看）

> 编码：企业智能-261022-18 ｜ 类型：fact ｜ 记录于 2026-10-22T10:38:13Z

1. **财务数据不碰 AI**（安逸明确）：AI 只做制作工具，执行靠工具/人工。
2. **平台数据获取受限**：拼多多反爬严格（需 RPA / 云手机）；抖音、视频号部分靠人工导出；视频号仅二维码登录，无法自动化。
3. **飞书自动化 vs 程序写状态的竞态**：「已完成 / 请处理反馈 / 转交内容部」三终态的写入权归属待现场核实；收敛前需防竞态（approve 前先核 flow_status）。
4. **素材缺口**：白底图 / 样机图 / logo 等客户素材是 P0 前置；未到则任务自动挂起「等待素材」。
5. **主体边界**：船长花园是客户主体；本空间内部可用真实名，对外产物需按边界规则脱敏。

## 为什么单列一条
前三项都是「客户一问就可能漏馅」的地方。谈单时主动说出来，比被追问好。
