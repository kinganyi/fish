# 素材命名与画面内容：三个易错点

## 1. 场景不能用角色风格前缀

**错**（安逸 2026-10-23 指出）：把场景写成 `@真人-办公室夜`、`@真人-数据中心`、`@真人-工位区`。

**根因**：`真人-` / `3D卡通-` 是**角色素材**的风格前缀（同一角色在真人风格与卡通风格下有两套图，靠前缀区分）。场景图没有“风格分岔”，套用这个前缀是误用。

**对**：
- 角色：`@真人-苏姐`、`@真人-林涛`（保留风格前缀）
- 场景：`@场景-办公室夜`、`@场景-数据中心`、`@场景-工单屏`（用“场景-”前缀）

## 2. 不要在提示词里写“画面内浮出字幕”

**错**：`画面下方浮出一行字幕：“FDE ＝ 前沿部署工程师……”`

**根因**：成片本来就会统一加字幕。“画面内浮出字幕”会与后期字幕叠加，且 AI 生成中文字幕不可控。

**对**：需要解释的术语直接写进口播台词（“用的就是 FDE——把工程师派进你的业务现场”），字幕交后期。

## 3. 第一帧必须有真人开口

空镜开场（先给办公室全景再切入）会拖慢前 3 秒。**第一帧就要有人物开口**，环境信息靠背景堆叠，不靠空镜交代。

## 4. 数字动效四段式（质量要求）

不是“亮起”也不是简单“砸下”，要有层次：**推近（半透明轮廓）→ 实体化 → 冲击波扩散 → 环境反应**（纸张被掀、头发被吹、水面震荡）。
