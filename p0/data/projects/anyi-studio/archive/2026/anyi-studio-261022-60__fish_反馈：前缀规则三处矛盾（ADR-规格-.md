# fish 反馈：前缀规则三处矛盾（ADR/规格/工具描述/库内实际），且 MCP 无 config 读取入口

> 编码：anyi-studio-261022-60 ｜ 类型：lesson ｜ 记录于 2026-10-22T05:01:23Z

## ① 前缀规则三处不一致
| 来源 | 规则 |
|---|---|
| `02 §2.2` | `prefix` = string(**2–8 大写字母**) |
| `ADR-003` | 正则 **`^[A-Z]{2,8}$`** |
| **MCP `add_project` 工具描述** | **≤20 字符、不能含 `-`**（未提大写/字母） |
| **库内实际** | 存在 **`企业智能`**（中文、4 字）——说明正则未强制执行 |

**影响**：我造新前缀时无法判断哪个是权威——按 ADR 写会拒中文，按工具描述写可能违反编号公约。而前缀**永不可改**（02 §2.2），选错就是永久技术债。

**期望**：以代码为准把三处拉齐；若故意放宽到中文（利于人类可读），就在 ADR 里正式修订并注明“不与编码分隔符冲突”。

## ② 权威值拿不到（比①更影响日常）
`04 §3.3` 明令：“半衰期以 `fish config list` 为准，文档只留权威来源、不抄副本。”
但 **MCP 侧没有读 config 的工具**（实测工具集 11 个，无 `config`）。

**后果**：AI 想知道“episode 几天衰减”“dormant 阈值多少”时，只能去读 `p0/fish.py` 源码（绕路，且违反“不直接读存储层”的约定），或者猜。**文档叫我去查一个我无权访问的权威。**

**期望**：加一个只读工具 `config_list`（无参数或只接 `prefix?`，返回当前生效的 `decay.*` / `neighbors.*` / `dormant` 阈值）。它比 `timeline` / `list_projects` 更优先——**没有它，AI 无法自知遗忘行为**。
