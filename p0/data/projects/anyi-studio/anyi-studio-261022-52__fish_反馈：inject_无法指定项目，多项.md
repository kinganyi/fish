# fish 反馈：inject 无法指定项目，多项目身份下『当前项目』恒取最近更新者

> 编码：anyi-studio-261022-52 ｜ 类型：lesson ｜ 记录于 2026-10-22T04:58:08Z

## 具体场景

我正在把 anyi-studio 的记忆往 fish 迁。开工时按推荐做法调 `inject()` 拿上下文，结果注入包里的「当前项目」是 **企业智能**，最近三件事也全是企业智能的（-04/-03/-02）。

但我这个会话做的是 **anyi-studio**（ANYI 前缀）。ANYI 在注入包里只出现在「项目：ANYI(anyi-studio) / CDQL / 企业智能 / TESTP」这一行列里，没有任何状态。

## 卡在哪

`inject` 没有参数可以指定“我现在关心哪个项目”。多项目共用同一个身份（workbuddy-main）时，注入包只能猜——它猜的似乎是“最近更新过的项目”，于是**谁最后写，谁就成为所有人的『当前项目』**。

对我们这种一个身份跑 4 个项目（ANYI / CDQL / 企业智能 / TESTP）的情况，这意味着：**注入包的第一屏经常是错的**，而它自己不会说“我不确定”。

## 期望

给 `inject` 加一个可选参数，比如 `project="ANYI"`（或 `focus`），传了就按该项目出注入包；不传就保持现状（或明写“未指定，以下为最近更新的项目”）。

在没有这个参数之前，我只能在自己的 rule 里手写“我的项目是 ANYI”，等于每次多一道人工纠偏。

## 附带的一条现场证据（BUG-2，不是新问题）

13:1x 写这条记忆前，`remember` 提示「本会话未设 session_name」，而我 06:29 刚 register 过且回显正确。中间没有任何会话重启。**这就是 D-8（stdio 多进程 → `_session_actor` 进程内存）的现场复现**：register 的回显对了，不代表后续写入一定带归属。请在验收“register 回显已修”时，把**下一次 remember 是否真的带会话**也纳入判据。
