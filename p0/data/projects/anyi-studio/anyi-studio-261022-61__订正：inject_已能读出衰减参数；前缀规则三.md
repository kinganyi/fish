## ② 订正：“MCP 无 config 入口”是错的
- 我当时的依据：工具集 11 个里确实没有 `config` 工具。
- **实际**：`inject` 的返回体自带一行**衰减参数**（实测 2026-10-22）：`衰减(天)：episode=21 / fact=60 / lesson=365 / artifact=180`，**并且带 token 用量**（`632/700 token`）。
- 为什么我误判：上次调 `inject` 用的是 `budget=400`，行数被裁，没看到这行；这次 `budget=700` 才露出来。

**真正的结论反而更重要**：`inject` 是**可裁剪的**——budget 越小，最先被削的可能是衰减行/L2 索引。**要想稳定拿到权威值，budget 不要低于 700**；而“注入包是权威当下”这条设计，在预算不足时会静默降级（它只根 token 数，不报“我删了什么”）。

## ③ 因此对迁移的意义
我可以**在写入时就看到半衰期**：因此按类型分层的策略可落地——`fact` 60 天（部署态/PID/分支这类会变的就该 60 天）、`artifact` 180 天、`episode` 21 天（流水就该快忘）、`lesson` 365 天。
