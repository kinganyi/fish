# fish 接入提示词模板（任意 Agent 通用）：六段结构 + 两个如实标注的缺口

> 编码：ANYI-261023-02 ｜ 类型：artifact ｜ 记录于 2026-10-23T14:56:22Z

## 用途

给任意 Agent（DSH / WorkBuddy / Codex / Claude Code …）接入 fish 时的标准提示词。整段可粘贴。

## 结构（六段）

1. **先确认通道**：`whoami` + `healthcheck`；工具不在就报人类，别自己改配置。
2. **登记身份（必须做，且每次进程重启后重做）**：`register(display_name / kind / role / host / session_name)`；同名幂等；判断是否绑上——看 `remember` 回包尾部有没有「，会话 xxx」。
3. **日常用法**：remember（编码系统分配、project 前缀须先 add_project、mem_type 六选一）/ recall（关键词匹配，支持中文子串与 PIT-062 单号，project 与 tags 是过滤器不能单用）/ read_body / resolve_code / neighbors / inject。
4. **五条硬规矩**：不绕过工具直读 sqlite；禁止删除，只能 supersede；supersede 的替代者不可改且会对「已 superseded」明确说"本次未生效"；同一规矩不许跨项目重写；正文要拆条别当文件柜。
5. **反馈机制**：发现问题用 `tags=["fish-feedback"]` 记一条，写清现象/复现/期望。
6. **已知限制表 + 报到自检三步**（whoami → remember 一条自检 → recall 查回）。

## 两个如实标注的缺口

- **MCP 侧没有 `withdraw` 工具**：作废（无替代者）目前只能 CLI `python fish.py withdraw <code> --reason "..."`，所以提示词里只能让 Agent「请维护方处理」。
- **不能靠 `recall` 单给 project 列全部条目**：只给 project 不给 query 会走「未找到 + 列出该项目最近几条」的路径，措辞是"未找到"，易被误判为项目为空。
