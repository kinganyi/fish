# fish 反馈：接入顺畅无阻断；recall 短中文词不命中/编码跨天无时区说明/recall 缺会话标注三点可改进

> 编码：ANYI-261024-05 ｜ 类型：lesson ｜ 记录于 2026-10-23T16:34:44Z

## 现象
本会话（anyi-studio-审查B，zcode 宿主）完整用了 whoami / register / remember ×4 / recall ×5，四步接入自检一次全过，幂等、编码分配、禁删规则均与文档一致。**三个可改进点**：

1. **recall 对短中文词查不到（本轮新发现，可稳定复现）**：标题含「反馈」二字，但 recall(query="反馈") 返回未找到；"fish 反馈"同样未找到；而 "接入顺畅"（4 字）、"fish 反馈：接入顺畅"（长句）、精确编码均能命中。疑似 CJK 查询片段存在最小长度/分词阈值（两字词打不中索引）。
2. **编码日期跨天无时区口径说明**：23:0x 写入分到 ANYI-261023-05，十几分钟后 00:0x 写入分到 ANYI-261024-01/02——编码在会话中途跳天（本地时区跨零点）。功能无碍，但按本地日期推码会错，回包与文档均未说明编码用哪个时区。
3. **recall 结果不带会话/宿主标注**：recall("接入自检") 命中审查A、审查B 两会话的同标题条目，回包只有编码+类型+标题+匹配来源，无法直接分辨是哪个会话写的，须逐条 read_body 或凭编码时间推断。

## 复现
1. recall(query="接入自检") → 命中 ANYI-261023-04/05 两条同标题条目，无会话名字段。
2. 写入标题「fish 反馈：接入顺畅无阻断；编码跨天…」的条目（ANYI-261024-04）后：
   - recall(query="反馈") → 未找到（标题含此二字）
   - recall(query="fish 反馈") → 未找到
   - recall(query="接入顺畅") → 命中（匹配：标题）
   - recall(query="fish 反馈：接入顺畅") → 命中（匹配：标题）
   - recall(code="ANYI-261024-04") → 命中（匹配：编码）
3. register(display_name="zcode-main", kind="role", host="zcode", session_name="anyi-studio-审查B") → 「已存在，直接使用：1792…4 / zcode-main / role，会话 anyi-studio-审查B」——幂等复用+会话名一次绑定成功，无需预案中的二次调用。

## 期望
1. recall 修复或文档声明 CJK 最小查询长度（如「中文关键词至少 3-4 字，两字词请用编码或更长词组」）；当前 ADR-006 提示只说了「同义词查不到」，没说「短词查不到」。
2. remember 回包或文档注明编码日期的时区口径（如「编码取 UTC 日期」）。
3. recall 回包在条目行附带写入时的 session_name（或 host），多会话同标题条目可直接区分。
其余保持现状：register 幂等、编码系统分配、禁删+supersede、工具描述内嵌规则，对新会话很友好。
