# 工作空间迁入 fish 的分层策略：只迁结论与索引，不迁原文正文

> 编码：ANYI-261022-50 ｜ 类型：rule ｜ 记录于 2026-10-22T04:57:41Z

## 一句话
**只迁「结论」，不迁「原文」。** 2000+ 篇文档继续留在工作空间当原料，fish 只做「索引 + 决策 + 教训」层。

## 为什么不能全迁（三条硬约束）
1. `recall` 只能命中标题/关键词（分词 AND→降级 OR），**不检索正文、不检索 tags、无 `project` 过滤**（07 §D-5）。全量正文迁进来 = 存得进、查不出。
2. `timeline` / `list_projects` **未实现**（D-4）⇒ 无法按项目/时间盘点，只能逐条查。
3. `withdrawn` / `valid_until` **未实现**（D-6/D-7）⇒ 迁错或过期的记忆**不能作废、不能自动失效**，只能删文件。

## 按 mem_type 分层（"不可折叠"五要素的落地）
| 工作空间资产 | 迁入类型 | 理由 |
|---|---|---|
| ER-1~31 工程铁律 / CR-1~15 协作约定 | `rule` | 规范权威，**永不衰减**，L0 注入 |
| 会话身份/协议/角色边界 | `identity` | 自我解释，永不衰减 |
| PIT-001~102 错题本 | `lesson` | 教训，慢衰减，按需 |
| 架构设计/送审包/交接报告 | `artifact` | 谱系载体，中衰减，只迁**结论与路径** |
| 部署态/分支/PID/主机等现状 | `fact` | 会变，**快衰减是对的** |
| daily 日志 / 台账 | `episode` | 流水，最快衰减；只迁「当天定下的决策」 |

## 明确不迁
- 原文正文（`.md` 全文）—— 留在工作空间，fish 只存指针
- 一次性排障输出、日志、临时脚本
- 会被 fish 自己快速衰减、却占编码的流水

## 分批（首周测试期）
- **P0（本轮）**：工作空间地图 + 迁移策略 + 能力边界（3 条）
- **P1**：ER 铁律与 CR 约定分组迁（每组 1 条，不逐条拆）
- **P2**：PIT 错题本按主题合并
- **P3**：daily 只迁决策行；artifacts 只迁结论段

## 前置（未满足则不进 P2 之后）
`recall` 补 `project?` / `tags?`（D-5）或 FTS5（A2 决策）；否则 P3 体量下会退化成「只能靠编码翻」。

## 写入规范（每条必须自包含）
标题即检索面：`<主题>：<结论>`（≤80 字），关键词进 tags，正文首段给结论、末段给路径。**不要写「详见上文」——没有上文。**
