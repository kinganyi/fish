# PIT 错题本·外部集成与错误语义

> 权威源：`notes/error-ledger.md`。场景：接上游模型/网关、飞书字段、审核码、凭证回显。

## 本质

外部系统不会“告诉你错了”，它只会**静默丢弃、换个说法、或返回一个笼统的外壳文案**。看上去成功，实际功能已失效。

## 何时该想起

接新上游/新渠道、改字段名、处理审核错误、改凭证读取、写脱敏日志。

## 关键判据

1. **字段名不匹配 = 静默丢弃**：网关把参数当没传，功能等同失效（PIT-053）；参数转换遗漏会在生产全链失败（PIT-065）。
2. **错误文案要看逗号后**：上游“资源同步失败”只是外壳，真实原因在后面（PIT-028）；审核码有多个家族，漏一个 → 文案不收敛 + 健康度误伤（PIT-029）。
3. **按名取值要防改名**：飞书字段改名后按名取值静默落空（PIT-022）。
4. **“唯一前缀匹配”容错是陷阱**：空值字段 + 相似名会匹错（PIT-023）。
5. **隐式凭据回退会掩盖配置缺失**：“能读”不等于“配置正确”（PIT-021）。
6. **脱敏正则要覆盖多种引号形态**：否则 AccessKey 会落入 transcript（PIT-084）。
7. **模型改名要同步分类**：改名后文本分类漏判（PIT-007）。
8. **中文的 `str.isalpha()` 也返回 True**（PIT-026）：判变体字母时不能只看字符类。
