# anyi-studio 不存 PHP2Shell 攻击面：生产无 PHP 运行时（CVE-2026-109618/109619 排查留痕）

> 编码：ANYI-261022-113 ｜ 类型：fact ｜ 记录于 2026-10-22T10:12:03Z

# 结论

**不存在。** anyi-studio 生产站点不构成 PHP2Shell（CVE-2026-109618 / CVE-2026-109619）攻击面 —— 无需升级、无需缓解措施。

# 漏洞触发前提（判据）

两个 CVE 的唯一入口是「Web 服务器把请求交给 PHP 解释器处理」，载体只有五种：**PHP-FPM / mod_php / php-cgi / FrankenPHP / LiteSpeed**。

背景事实：
- 影响 PHP 5.4 起几乎全版本（含 7.x、8.0/8.1）；修复版 **8.2.35 / 8.3.36 / 8.4.27 / 8.5.12**
- 危险评分 9.2，**未登录即可 RCE**：-109618 走 OOM → 内部数据结构不完整 → 内存破坏；-109619 走 use-after-free
- 发现方：GPT-5.6 Sol（OpenAI Patch the Planet）与 Wiz 独立发现
- 官方**无完整缓解措施**，唯一安全做法是升级

我方五种载体**一个都没有** ⇒ 攻击面为零。

# 实际技术栈

```
nginx (80/443) → 反代 → Python FastAPI (:8765) → PostgreSQL 16 (docker，仅绑 127.0.0.1)
                                               → Node 容器 (dsh-worker / dsh-spike)
```

全链路无 PHP 解释器、无 PHP 软件包、无 CGI/FastCGI 处理器。

# 复现（对任一待查机器）

```bash
which php
dpkg -l | grep -i php
dpkg -l | grep -Ei 'apache2|httpd|litespeed|frankenphp'
grep -riE 'php|fastcgi_pass' /etc/nginx/sites-enabled/ /etc/nginx/conf.d/
ss -lntp
docker ps
```

判据：五种载体**任何一个非空** ⇒ 需评估；**全空** ⇒ 安全。非 Debian 系把 `dpkg -l` 换成 `rpm -qa`。

# 同类通告的通用提醒

判断「某运行时漏洞是否影响我方」的正确顺序是 **先核有没有该运行时**，而不是先看版本号。没有运行时 ⇒ 版本再旧也无关。这条对本项目适用面较广：我方是 Python/Node 栈，**所有 PHP / Java / .NET 类 CVE 默认与我无关**，除非将来引入对应运行时。
