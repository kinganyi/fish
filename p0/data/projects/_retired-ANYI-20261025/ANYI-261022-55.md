# 工作产出落 fish 的约定（新产出进库 / 存量只建指针）

> 编码：ANYI-261022-55 ｜ 类型：rule ｜ 记录于 2026-10-22T04:58:39Z

## 决定（安逸 2026-10-22 批准）

**新产出直接进 fish（记忆 + 附件），存量不搬、只建指针。**

## 具体做法

1. **新文档**（回执 / 送审包 / 报告 / 方案）→ 先写到工作区，再 `remember` 一条 `artifact` 记忆，用 `attachments` 把文件挂上去（系统按 SHA256 去重）；body 写摘要 + **源文件路径**，保证可回溯。
2. **存量 2067 个文件不搬**。理由：一次性把 2000+ 文件搬进去会把 `recall` 的**标题面**淹没（而 recall 只搜标题与编码），反而更难找。需要时按主题补建指针记忆。
3. **工作空间只留构建产物**（dist/、打包 tar、临时脚本），文档类以 fish 为准。
4. **一条产出 = 一条记忆**，标题写清「是什么 + 日期」，不要把多份文档塞进一条。
5. 大文件（>10MB）不进附件，只在 body 写路径 + sha256。

## 边界（如实的）

- fish 是**索引层**，不是文档仓库；正文能进 body 就进 body，附件只给“需要原样存档”的东西。
- 附件目前**无删除/替换手段**（观察期内），所以上传前先定稿。
